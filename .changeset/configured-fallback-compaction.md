支持在 `~/.pi/agent/extensions/pi-codex-compaction/config.json` 中指定降级压缩模型和思考等级。V2 关闭、远程压缩失败或当前模型不支持 Remote Compaction V2 时，使用已启用的配置模型生成 Pi 原生文本摘要，压缩后继续使用原来的对话模型。

已启用的降级模型在配置、认证、请求或摘要校验失败时停止压缩，避免再次交给当前对话模型。复用 Pi 的消息准备、最近消息保留、文件记录、用量和重试机制，保持现有 Codex 检查点格式。

新增 `/codex-compaction` 配置菜单，支持搜索已认证模型并选择受支持的思考等级。终端开关按回车原地切换并立即保存，关闭保留模型和思考等级。开关和模型分别配置，仅两者齐备时启用；只开启开关仍按未启用处理。配置新增布尔字段 `fallback.enabled`，旧配置省略时保持启用。取消模型选择不保存该次选择；保存时检查外部修改，并使用 Pi 的文件写入队列原子替换配置文件。

新增 `Remote Compaction V2` 总开关，复用 Pi 设置列表按回车直接切换。配置字段 `remoteCompaction.enabled` 默认开启，保存时明确写入 `true` 或 `false`；关闭后跳过新 V2 请求，进入指定模型或 Pi 默认文本压缩，保留已有 opaque 检查点重放。压缩开始时固定配置，格式错误停止压缩，后续修改应用于下一次压缩。
